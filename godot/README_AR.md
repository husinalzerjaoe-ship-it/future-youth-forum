# مشروع مغامرات Godot — ملتقى شباب المستقبل

## المحتوى الحالي
مشروع Godot 4 ثلاثي الأبعاد مستقل، ويحتوي على ثلاث تجارب قابلة للعب داخل المشهد نفسه:

1. **كنز الجزر:** استكشف الساحة واجمع 12 جوهرة.
2. **سباق الحواجز:** اقفز فوق الحواجز واجمع الشارات.
3. **صياد الأهداف:** تحرك في الساحة واجمع 10 أهداف مضيئة.

يوجد لاعب ثلاثي الأبعاد، كاميرا منظور ثالث، أرضية وتصادمات، إضاءة، أزرار لمس للحركة والقفز، وأزرار للتبديل بين التجارب. الأشكال والمواد مولّدة من موارد Godot الافتراضية ولا تحتاج ملفات أصول خارجية.

## فحص المشروع
الإصدار المستهدف: **Godot 4.7.2-stable**. يوجد فحص آلي في GitHub Actions لتحميل نسخة المحرك الثابتة وتشغيل فحص الاستيراد والتشغيل headless عند تعديل مجلد Godot.

## حالة الدمج واللعب الجماعي — اقرأ قبل الاختبار
- تم ربط محرك Godot 4.7.2 كتطبيق Android Library (AAR) ويُفتح من مركز الألعاب داخل تطبيق Flutter عبر شاشة Android داخلية باسم GodotGameActivity. ينسخ سير البناء ملفات المشروع إلى أصول APK ويضيف اعتماد المحرك تلقائياً.
- التجارب الثلاث داخل Godot حالياً **فردية**؛ لا توجد مزامنة لحركة اللاعبين داخل مشهد Godot حتى الآن.
- لعبة «عالم الأصدقاء التعاوني 2D» منفصلة عن Godot، وتستخدم غرف Firestore الخاصة مع مزامنة حركات اللاعبين ودردشة نصية داخل الغرفة وزر فويس LiveKit.
- لا نعلن أن دردشة/فويس Godot أو مزامنة Godot جاهزة قبل تنفيذ جسر Android/Flutter واختبارها على جهازين.

## الدمج الحالي وما يحتاجه الإكمال
1. اعتماد Godot Android Library الرسمي `org.godotengine:godot:4.7.2.stable` من Maven Central.
2. يضيف سير بناء GitHub Actions شاشة `GodotGameActivity` ويضم ملفات المشروع إلى أصول APK.
3. يفتح Flutter الشاشة عبر MethodChannel من مدخل «مغامرات Godot 3D» في مركز الألعاب.
4. لا يوجد بعد جسر مزامنة شبكية لحركة لاعبين Godot ثلاثية الأبعاد. لا نعلن اللعب الجماعي 3D جاهزاً قبل إضافة خادم لحظي واختبار جهازين فعليين.
5. لا تتغير غرف المشاهدة أو نظام المكالمات الحالي.

## التشغيل على جهاز تطوير
افتح مجلد `godot/` في Godot 4.7.2-stable وشغّل `res://scenes/main.tscn`. داخل التطبيق، افتح مركز الألعاب ثم «مغامرات Godot 3D» ثم اضغط تشغيل. يجب نجاح بناء Android بعد تنفيذ `scripts/configure_godot_android.py`.
