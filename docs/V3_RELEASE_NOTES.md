# ملتقى شباب المستقبل — V3

## الهوية والتصميم
- اعتماد اتجاه أنمي سينمائي ممزوج بواجهات زجاجية، بألوان بنفسجية وزرقاء وكحلية.
- الإبقاء على أقسام ومزايا V2 دون حذفها.

## تجربة الاستخدام
- شريط موسيقى مصغر ثابت داخل التطبيق يعرض اسم المقطع والفنان والوقت وشريط التقدم، مع السابق والتشغيل/الإيقاف والتالي والتقديم بالسحب.
- لوحة قابلة للطي للرسائل المثبتة في المحادثة العامة، مع الإبقاء على صلاحيات التثبيت الحالية.
- إصدار Android: 3.0.0+10.

## ملاحظات التحقق
- يتطلب اعتماد الإصدار نجاح Flutter analysis وبناء APK release في GitHub Actions.
- يعتمد المشغل على خدمة الصوت الحالية، وتعتمد لوحة المثبتات على حقل isPinned الموجود في رسائل الدردشة.
