# V47 — مكتبة IPTV مشتركة

## السلوك
- أي قائمة M3U/M3U8 يستوردها المؤسس من رابط أو ملف تُحفظ محلياً ثم تُنشر تلقائياً إلى مكتبة IPTV المشتركة.
- الأعضاء المسجلون يقرؤون المكتبة المشتركة مباشرة داخل مركز IPTV دون إدخال رابط القائمة.
- تحديث القائمة يعيد نشر قنواتها ويستبدل قنوات الإصدار السابق لنفس المصدر.
- القوائم المحلية الحالية تبقى محفوظة ومتاحة، ولا تُحذف بسبب إضافة المزامنة.
- القنوات المشتركة تظهر مع القنوات المحلية، ويُمنع تكرار رابط القناة إذا كان موجوداً محلياً بالفعل.

## الأمان
- قراءة المكتبة متاحة للمستخدمين المسجلين فقط.
- النشر والتعديل والحذف محصور بحساب المؤسس وفق تحقق البريد الموجود في قواعد Firestore.
- روابط القنوات ومعلومات المصدر تُشارك مع أعضاء التطبيق؛ لا تستخدم قوائم خاصة أو روابط تحتوي بيانات دخول أو رموز وصول لا تريد كشفها.
- لا تتجاوز الميزة اشتراكات القنوات أو DRM أو المصادقة أو القيود الجغرافية؛ يجب أن تكون مصادر البث قابلة للمشاركة قانونياً.

## التخزين والقيود
- بيانات المكتبة المشتركة محفوظة في Firestore ضمن `iptvSharedPlaylists` مع قنوات فرعية.
- القوائم المحلية والمفضلة ودليل XMLTV تبقى محلية كما كانت.
- يلزم نشر قواعد Firestore المحدثة مع هذا الإصدار حتى تعمل المزامنة.
- يلزم تسجيل الدخول بحساب المؤسس للنشر؛ إذا فشل النشر تبقى القائمة محفوظة محلياً ويظهر تنبيه.
- المزامنة تحتاج اتصال إنترنت وحساب Firebase مسجل.

## فحوصات ما قبل الدمج
- Flutter tests وanalyze.
- Android release APK build.
- اختبار عملي بحساب المؤسس على جهاز، ثم فتح IPTV بحساب عضو آخر والتأكد من ظهور القائمة.
- اختبار إعادة استيراد قائمة موجودة، ملف محلي، وقائمة رابط.
