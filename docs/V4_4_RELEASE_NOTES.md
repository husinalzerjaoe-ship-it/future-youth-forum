# ملتقى شباب المستقبل — V4.4.0+15

## إضافات وتحسينات المكالمات
- إضافة فلاتر عرض فيديو محلية: طبيعي، أبيض وأسود، دافئ، بارد، وبنفسجي.
- إضافة تبديل مخرج الصوت بين مكبر الصوت وسماعة الهاتف.
- إضافة نسخ رمز الغرفة بسرعة لمشاركته مع الأصدقاء.
- عرض عدد المشاركين بصورة أوضح.
- الفلاتر تغيّر العرض على الجهاز فقط ولا تعدّل بث الفيديو الأصلي أو تحفظ نسخة منه.

## إضافات الدردشة
- إضافة بحث مباشر في آخر 100 رسالة محمّلة من الساحة العامة.
- البحث يشمل نص الرسالة واسم العضو.
- إضافة زر لمسح البحث ورسالة واضحة عند عدم وجود نتائج.
- الحفاظ على الرسائل الصوتية والصور والملصقات والمنشن والردود والتفاعلات والخلفيات والتثبيت والبلاغات وأدوات الإدارة الموجودة.

## تحسينات الصيانة
- تصحيح تعليق إعداد Firebase/Supabase حتى يطابق سياسات التخزين المحدّثة.
- تحديث رقم التطبيق إلى 4.4.0+15.

## ملاحظات التشغيل
- فلاتر الفيديو الحالية مؤثرات عرض محلية وليست مؤثرات تجميل بالذكاء الاصطناعي.
- المكالمات تحتاج نشر Cloudflare Worker وإضافة LIVEKIT_API_KEY وLIVEKIT_API_SECRET في Cloudflare، ثم حفظ رابط Worker داخل التطبيق واختبار جهازين.
- لا يتضمن هذا الإصدار تغييراً لقواعد Firestore المنشورة؛ لا تنشر قواعد جديدة لمجرد هذا التحديث.
- يجب نجاح Flutter analysis وبناء APK release قبل اعتماد النسخة.
